RPN计算器使用手册

基于C++实现的逆波兰表示法计算器 - 完整使用指南

项目概述

这是一个基于命令行界面的逆波兰表示法（Reverse Polish Notation）计算器，使用C++编写核心逻辑，支持基本四则运算和高级数学函数。

安装和编译指南

环境要求

  • Ubuntu Linux 系统
  • g++ 编译器
  • 标准 C++ 库

编译步骤

# 进入项目目录
cd ~/Work/rpn_calc

# 编译程序
g++ rpn_calc.cpp -o rpn_calc -lm

# 运行程序
./rpn_calc
注意： 编译时务必加上 -lm 参数，这是链接数学库所必需的。

错误代码和异常说明

错误类型错误信息原因解决方法
栈空错误错误: 栈为空尝试从空栈中弹出元素先输入数字再执行操作
栈元素不足错误: 栈元素不足二元操作时栈中元素少于2个确保栈中有足够元素
除零错误错误: 除零错误除数为0检查输入的数字
负数平方根错误: 负数不能开平方根对负数进行平方根运算输入非负数
未知操作符错误: 未知操作符 'X'输入了不支持的操作符检查操作符拼写
斐波那契输入错误错误: 斐波那契数列需要非负整数输入了负数或非整数输入非负整数
