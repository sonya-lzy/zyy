## 项目概述
基于C++实现的逆波兰表示法（Reverse Polish Notation）计算器，支持基本四则运算和高级数学函数。

## 功能实现

### 基础功能
- ✅ 四则运算（+、-、*、/）
- ✅ 数字输入（整数和浮点数）
- ✅ 栈操作（清空、显示）
- ✅ 错误处理（除零、栈空、格式错误）
- ✅ 连续运行操作

### 高级功能
- ✅ 更多数学运算（sqrt、pow、sin、cos）
- ✅ 斐波那契数列计算（fib）
- ✅ 批量表达式计算支持
- ✅ 计算历史记录

# 编译
g++ rpn_calc.cpp -o rpn_calc -lm

# 运行
